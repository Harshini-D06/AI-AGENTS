# 🧳 Mini Autonomous Travel Agent

A Python-based Mini Autonomous Travel Agent that plans a trip based on user preferences such as destination, transportation, budget, hotel preference, travel date, and interests.

The agent demonstrates important AI-agent concepts such as:

- 🎯 Goal setting
- 🧠 Memory
- 📋 Planning
- 🔧 Tool usage
- 🧠 Reasoning and decision making
- 👀 Observation
- 🔄 Re-planning after failure
- 👤 Human-in-the-loop approval
- 📊 Final itinerary generation


## 🎯 Project Goal

The goal of this project is to create an autonomous travel planning agent that can:

1. Understand the user's travel requirements.
2. Search transportation options.
3. Evaluate available options.
4. Select a suitable transportation option.
5. Search for hotels.
6. Check weather conditions.
7. Find places to visit.
8. Calculate the estimated trip cost.
9. Re-plan when the selected option is unavailable.
10. Ask the user for final approval.
