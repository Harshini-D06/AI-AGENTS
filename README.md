# AI-AGENTS

This repository contains multiple independent AI agents developed as modular projects.

Each AI agent is maintained in its own folder and can be run independently.

---

## Agents

### 1. Study Plan Management Agent

A Python-based agent that creates a personalized study schedule based on:

- Student name
- Number of study days
- Daily study hours
- Selected subject

It generates a timetable containing study topics, revision sessions, and Previous Year Question Papers (PYQs).

#### How to Run

```bash
cd study-plan-agent
python3 study.py
