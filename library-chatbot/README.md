# College Library Chatbot

## Description

The College Library Chatbot is an independent Python-based terminal application that helps students search and check books in a college library.

## Features

- Display all books
- Search books by title
- Search books by author
- Search books by subject
- Check book availability
- Help menu
- Exit option

## Technologies

- Python 3

## Requirements

Python 3.x

No external Python libraries are required.

## How to Run

Open the terminal inside this folder:

```bash
cd library-chatbot
