# Study Plan Management Agent

## Description

The Study Plan Management Agent creates a personalized study schedule based on:

- Student name
- Number of study days
- Daily study hours
- Selected subject

The agent generates a daily timetable containing study topics, revision sessions, and Previous Year Question Papers (PYQs).

## Features

- Personalized study schedule
- Subject-wise topics
- Daily revision
- Previous Year Question Papers
- Individual timing for topics and PYQs
- Simple Python terminal interface

## Technologies

- Python 3

## Requirements

Python 3.x

No external Python libraries are required.
